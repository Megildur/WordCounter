# WordCounter

A high-performance Discord bot for tracking words, messages, attachments, media links, and custom keywords across your server with real-time analytics, monthly history breakdowns, and retroactive chat sweeps.

## 🔗 Links

- **Discord Server**: [Join our Discord Server](https://discord.gg/Hr595Zk2tr)
- **Add Bot to Server**: [Install WordCounter](https://discord.com/oauth2/authorize?client_id=1551875701748277299&integration_type=0)

## ✨ Features

- **Live Activity Tracking**: Real-time counting of words, messages, attachments, media links, and custom keywords.
- **Monthly & Yearly Analytics**: All activity is categorized by month, year, and channel from newest to oldest.
- **Interactive User Stats**: `/stats user` displays overall server totals on top and month-by-month navigation underneath with channel breakdowns.
- **Unified Leaderboard**: `/leaderboard` with interactive category switching (Words, Messages, Attachments, Keywords) and channel monthly breakdowns.
- **Retroactive Chat Sweep**: `/analyze_chat` (single user or whole server) scans historical messages sent before the bot joined with smart anti-ratelimit pacing and dynamic ETA calculations.
- **Interactive Settings Dashboard**: `/settings` for managing watched/ignored channels and categories, keyword watchlists, and data resets.
