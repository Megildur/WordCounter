What it does

Every message, counted

Leaderboards for all of it

One command shows who leads in words, messages, attachments, emojis or keywords. Pick a channel to see its top members and its month-by-month history. Member stats show anyone's totals, then page through each month with a per-channel breakdown.

/leaderboard /stats user /keyword list

Live tracking

Every message in a tracked channel is counted as it's sent. Edit or delete a message and the counts are corrected. Attachments include files, stickers and links, and emojis include both standard and custom ones.

Counts from before it joined

Count one member's past messages using Discord's search, usually in a few minutes, or read every tracked channel, voice chat and thread in the server. Messages already counted live are skipped, so nothing is counted twice, and a long run picks up where it stopped if the bot restarts.

/analyze_chat single_user /analyze_chat whole_server

Your stats on the web

Log in with Discord to see your own counts in every server you share with WordCounter. If you can manage a server, you also get its leaderboards, every member's stats and its settings, here in the browser.

Keywords

Pick words or phrases your server cares about, like an inside joke or a game's name, and see who says each one most.

Your rules

Track the whole server with an ignore list, or only the channels and categories you pick. Reset counts for a member, a channel, both, or the whole server whenever you need a fresh start.

/settings
